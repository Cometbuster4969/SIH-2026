🏗 System architecture

Sensor-agnostic 512 px tiles / 64 px overlap, end-to-end — user query in, grounded answer + audit out.

Agentic layer (real, live) ingestion & validation → registry.yaml → guardrail → deterministic RuleRouter → executor → integrator → SQLite trace store. No hosted generic LLM on the graded path (PS P12).
Intelligence layer M1 Qwen2-VL-2B QLoRA (VQA · caption · 2-image) · M4 BiT change · M3 Grounding-DINO-T · M7 UNet++ patch (BIFOLD S1+S2 init). M5 = M1 in 2-image mode; M6 cut.
SAR is not RGB dB backscatter, multiplicative speckle, polarisation — kept intact in a separate encoder path; co-registration verified before any fusion.
What you can audit Every request emits trace.json — task, tool names, key parameters, per-step latency, confidence. That is exactly what the evaluation inspects (PS P10).
